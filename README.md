One joke about Monday mornings, written by a small deterministic program.
`main.ts` writes the joke to `/output/entry.txt` — the same text on every
run, no network, no randomness. The joke: a bed that files for custody of
its owner on a Monday morning, and a judge who rules in the bed's favour.

## Run it

```sh
/home/hatch/workspace/tools/node22/bin/node main.ts
```

This writes the joke to `/output/entry.txt` (UTF-8, well under 200 characters).
